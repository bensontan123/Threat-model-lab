    About Benson's Threat Model Lab

    A browser-based threat-modelling tool. Import an architecture diagram (draw.io, Mermaid, JSON or CSV) or build one by hand, then generate a threat model four ways — enterprise IT or OT/ICS (Purdue), each as STRIDE-LM or RAPIDS scenarios.

    Every path resolves to MITRE ATT&CK techniques. Each technique expands into an offensive attack/payload sample and the defensive side: Sigma, YARA and network detections plus mapped MITRE D3FEND countermeasures and ATT&CK mitigations.

    Methodologies

    • IT · STRIDE-LM — per component, the seven STRIDE-LM categories (incl. Lateral Movement).
    • IT · RAPIDS — Ransomware, Application vulnerability, Phishing, Insider threat, Denial of service, Supply chain.
    • OT/ICS Purdue · STRIDE-LM — per Purdue level, mapped to ICS + enterprise techniques.
    • OT/ICS Purdue · RAPIDS — the six scenarios adapted to OT/ICS.

    Safety & privacy

    For authorised security testing and education. OT process-manipulation payloads are bounded to recon/read or isolated test-rig examples. All parsing is client-side — no diagram or data leaves your browser.
